# TypeScript

The chapters of the official TypeScript handbook worth reading, in order.
Part of the [Frontend Roadmap](../README.md).

## Learn

- [Basics](https://www.typescriptlang.org/docs/handbook/2/basic-types.html) — How static types work and what the compiler checks.
- [Common Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html) — The everyday types you will write in most code.
- [Functions](https://www.typescriptlang.org/docs/handbook/2/functions.html) — Typing parameters, return values, overloads, and generics.
- [Object Types](https://www.typescriptlang.org/docs/handbook/2/objects.html) — Describing the shape of objects, including optional and readonly members.
- [Type Manipulation](https://www.typescriptlang.org/docs/handbook/2/types-from-types.html) — Building new types out of existing ones.
- [Classes](https://www.typescriptlang.org/docs/handbook/2/classes.html) — Class members, visibility, inheritance, and type parameters.
- [Modules](https://www.typescriptlang.org/docs/handbook/2/modules.html) — How TypeScript handles imports, exports, and module syntax.
- [Enums](https://www.typescriptlang.org/docs/handbook/enums.html) — Named sets of constants and how they compile.
- [Decorators](https://www.typescriptlang.org/docs/handbook/decorators.html) — Annotating and modifying classes and their members at declaration.

## Deep dives

- [Utility Types](https://www.typescriptlang.org/docs/handbook/utility-types.html) — Built-in type transformations such as Partial and Pick.
- [Declaration Files](https://www.typescriptlang.org/docs/handbook/declaration-files/introduction.html) — Writing and consuming .d.ts type definitions.
- [Iterators and Generators](https://www.typescriptlang.org/docs/handbook/iterators-and-generators.html) — Typing the iterable protocols and generator functions.
- [Module Resolution](https://www.typescriptlang.org/docs/handbook/module-resolution.html) — How the compiler locates the file behind an import.
- [Namespaces](https://www.typescriptlang.org/docs/handbook/namespaces.html) — The older, pre-modules way of grouping code.
- [Project Configuration](https://www.typescriptlang.org/docs/handbook/tsconfig-json.html) — tsconfig.json options and compiler settings.
