# UI Frameworks

CSS and component frameworks for building interfaces without starting from scratch.
Part of the [Frontend Roadmap](../README.md).

## Tools

- [Bootstrap](https://getbootstrap.com/) — The most popular HTML, CSS, and JS library in the world.
- [Bulma](https://bulma.io/) — Free, open source CSS framework.
- [UIkit](https://getuikit.com/) — Lightweight and modular front-end framework.
- [Semantic UI](https://semantic-ui.com/) — User interface is the language of the web.
- [Materialize](https://materializecss.com/) — Modern responsive front-end framework.
- [Pure CSS](https://pure-css.github.io/) — Set of small, responsive CSS modules.
- [Foundation](https://get.foundation/) — The most advanced responsive front-end framework.
- [Material UI](https://mui.com/material-ui/) — React components for faster and easier web development.
- [Material Design](https://m3.material.io/) — Design system, backed by open-source code.
- [Ant Design](https://ant.design/) — Design system for enterprise-level products.
- [Tailwind UI](https://tailwindcss.com/plus) — Beautiful UI components. [paid]
- [Chakra UI](https://chakra-ui.com/) — Build accessible React apps & websites with speed.
- [Clarity Design System](https://clarity.design/) — UX guidelines, an HTML/CSS framework, and more.
- [Reactstrap](https://reactstrap.github.io/) — Easy to use React Bootstrap 4 components.
